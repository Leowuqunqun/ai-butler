# 从零到「用微信遥控这台电脑」：三步

> 这份是给**完全不懂技术的人**看的 —— 你不需要知道什么是 Node、什么是 token。
> 每一步都只做两件事：**复制、粘贴**（或者扫码）。
>
> 原理和架构在 [产品架构](ARCH-product.md)、[技术架构](ARCH-technical.md) 里，
> 那是给开发者看的，看这份就够了。

---

## 想先试试？就在这台电脑上，十分钟

> 这条路**不换机器**。真正的验收走法在下面（换一台干净机器、从零走完整流程）。

**前提**：`~/.butler` 还不存在（`ls ~/.butler` 报「没有那个文件或目录」就对了）。
已经有的话先看看里面是不是你的数据，别硬来。

```sh
# ① 解开分发包（名字里的版本号以后会变，所以这里用通配），装（**离线**，十几秒：包里的 install.sh 用自带的 tarballs，不去网上取）
mkdir -p ~/butler-试 && tar -xzf butler-installer-*.tar.gz -C ~/butler-试
sh ~/butler-试/install.sh --no-start

# ② 写配置 —— **默认就是微信**，你什么都不用填
~/.butler/prefix/bin/butler init

# ③ 起来：先开一个网页让你贴模型 key；贴完它**再出二维码**，手机微信扫一下就上线
~/.butler/prefix/bin/butler run
```

第 ③ 步那个顺序是**故意**的：没填 key 之前它**连微信都不碰**（这一步我验过 —— 第一屏是
本地的模型 key 页，一个二维码都不会出）。扫码那一步只有你能做。

**想知道自己走到哪了**：

```sh
~/.butler/prefix/bin/butler doctor
```

还没贴 key 的时候它会明说，而且每条都带「怎么办」：

```
自检
  ✗  模型 key                还没有 —— 管家要靠它思考
      → 跑一次 butler run —— 它会自动打开一个页面让你把 key 贴进去，不用手写文件
```

### 如果这台电脑上已经有一个在跑的微信管家

先看有没有：

```sh
pgrep -fl "bridge.mjs run"
```

有的话要明白一件事：**两边登录的是同一个微信号**，新登录很可能把老的顶下来
（老的那个要重新扫码才能回去）。想留着老的就换一台机器跑这套；不在乎就直接往下走 ——
这是可逆的，重新扫码就回来了。

### 电脑不在同一个 WiFi（你在外面遥控家里那台）

两台都装 [Tailscale](https://tailscale.com/download)，**用同一个账号登录**，然后：

```sh
butler init --link tailscale     # 收微信的那台（中枢）
butler node                      # 被遥控的那台，屏幕上会打出一行
```

把那行（长这样：`配对 100.101.102.103:41338 4A7-K2M`）**发到微信里**就收下了。
不用填密钥、不用记 IP、不用在路由器上开洞 —— 那台电脑自己在哪个网都找得到。

### 装完之后能这么用它

| 你说 | 会发生什么 |
| --- | --- |
| `把 ~/Desktop/报告.pdf 发给我` | 文件发到聊天里 |
| `把刚才那张截图发给我` | **图片就是图片**（不是一个附件） |
| `这段视频发我` | 视频，手机上直接能播 |
| （直接把一张图 / 一个文件发给它） | 它落到 `~/.butler/inbox/`，并把**本机路径**交给 AI —— 于是它真能读你的东西 |
| （引用某句话）`这个改一下` | 它知道你在说哪句；回复开头也会带上你的原话 |
| 一个要干一会儿的活儿 | 它定期说「还在处理… 已 12s」，不让你干等 |
| `记住 简历都放 Documents/简历/` | 它记下来 —— 以后你说「把简历发我」，它知道去哪儿找 |
| （不用你说） | 你聊天里提到**长期有用**的事（偏好、常用路径、习惯、怎么称呼你），它会自己记下并当场说一声 |
| `记忆` | 列出它记得的事（带编号） |
| `你记得我什么` | 一样答得对：**每一轮请求前面都贴着这份记忆**，不用记什么命令 |
| `忘掉第 2 条` | 忘掉清单上的第 2 条（编号就是 `记忆` 列出来的那个） |
| 它要动你的电脑（删文件、装东西、跑命令） | **它会先问一声** —— 微信里弹一条「有件事要动你的电脑」，你点头它才动。旁边没人点"允许"的时候，它宁可不动 |
| `允许` / `允许 2` | 批了那件。只有一件在等的时候，光说 `允许` 就行 |
| `不许` / `不许 2` | 不准。**不答也一样** —— 到点我就当不许，绝不会先做了再说 |
| `待批` | 看看现在有哪些事在等你点头 |

> 另有 `butler init --im telegram` —— 那是用来**验证「通道可以换」**这条架构造的第二个通道，
> 不是这个产品的主线。微信才是。

## 开始之前：先把三样东西准备好（约 10 分钟）

| 你要有的 | 怎么弄 |
| --- | --- |
| **一台不关机的电脑** | Mac 或 Linux 都行。它得**一直开着、连着网** —— 它就是你的管家。装完之后这个终端窗口可以关掉（见下面「开机自己起来」） |
| **一个微信** | 手机上你已经有的那个就行。⚠️ 管家**只认第一个跟它说话的人**，所以别把二维码发给别人 |
| **一个模型 key** | 这是 AI 的"话费"，**要花钱**（几块到几十块）。5 分钟拿一个：打开 <https://platform.deepseek.com/api_keys> → 登录 → 「API keys」→ 新建 → 复制那串 `sk-` 开头的，先存到备忘录里 |

**如果你打算用 Telegram 收信**（微信之外的另一个选择），再多花 2 分钟：

4. 手机装 Telegram，在里面搜 `@BotFather` → 发一句 `/newbot` → 它会问你机器人叫什么，随便起
   → 最后它给你一串长得像 `123456:ABC-DEF…` 的 **token**，也存到备忘录里。

---

### 出发前：什么算「一台干净机器」

- **干净 = 从没装过这个管家**（`~/.butler` 不存在）。不用重装系统。
- **有没有 Node 都行**：没有的话，装的时候会自己下一份够新的（这步**要联网**，约 50MB）；
  已经有 Node 20 以上就**完全离线**装完，一个字节都不下。
- 这台机器**要能上网**（管家要连 AI、连微信）。
- ⚠️ 装完它会占住这个终端窗口（这是它的正常状态）。想让它开机自己起来，见下面。

<details>
<summary>没有第二台机器？拿临时目录演一遍也行（点开）</summary>

装的东西全在 `--home` / `--prefix` 两个参数指定的目录里，所以可以当"一台干净机器"来演：

```sh
# 从解开的分发包里跑（演练用，不碰你真正的 ~/.butler）
sh install.sh --home /tmp/butler-演练/home --prefix /tmp/butler-演练/prefix --no-start

# 连"这台机器压根没装 Node"都能演：把 PATH 里的 node 拿掉
env PATH=/usr/bin:/bin sh install.sh --home /tmp/butler-演练/home --prefix /tmp/butler-演练/prefix --no-start
```

演完 `rm -rf /tmp/butler-演练` 就行。**真机上的位置是 `~/.butler`**，演练不会碰它。

</details>

## 第 0 步：把它拿到手（约 1 分钟）

两条路，挑一条走。**装出来的东西一模一样** —— 路 A 拿到的就是路 B 那个包，区别只是谁替你解开。

**路 A：一行命令**（会打字就走这条，最快）

打开「终端」（macOS：聚焦搜索里敲"终端"），把下面这行**整行**粘进去、回车：

```sh
curl -fsSL https://github.com/Leowuqunqun/ai-butler/releases/latest/download/install.sh | sh
```

它会一路装完并启动 —— **直接跳到第 2 步**。

**路 B：下载整包、双击**（不想碰终端就走这条）

1. 打开 <https://github.com/Leowuqunqun/ai-butler/releases/latest>
2. 下那个 `butler-installer-….tar.gz`（几百 KB；名字里带版本号的和带 `latest` 的**内容一样**，下哪个都行）
3. **双击解开**（Mac 自带的解压就行）→ 接着看第 1 步

> 卡住了随时可以换另一条路 —— 两条路装完是同一个东西。

---

## 第 1 步：装上（约 2 分钟）

> 走了路 A 的话，这一步已经做完了 —— 直接跳到第 2 步。

1. 在解开出来的文件夹里找到 `install.command`，**双击它**
   - 如果系统弹窗说「来自身份不明的开发者」，**别点「移到废纸篓」**：在它上面**右键 → 打开 → 再点「打开」**。
     只需要做一次。
   - 双击没反应的，就打开「终端」（聚焦搜索里敲"终端"），把 `install.sh` 拖进终端窗口，回车。
2. 它会自己看着办：检查有没有够新的 Node（没有就自己从官网下一份并校验），
   然后装进 `~/.butler` —— **不要管理员密码，也不碰你系统里别的东西**。

> 不用先装任何东西。它自带一份 Node，装完之后 `butler` 用哪个 Node 跟你系统里的无关。

---

## 第 2 步：把该贴的贴进去，扫一下码

装完它会自己跑起来，**浏览器会弹出页面**。你只做「复制 → 粘贴 → 保存」：

| 顺序 | 页面问你 | 贴什么 |
| --- | --- | --- |
| ①（只有 Telegram 这条路有） | **Telegram 的 bot token** | 上面第 4 步存的那串 `123456:ABC-DEF…` |
| ② | **模型 key** | 上面存的那串 `sk-…` |
| ③（只有微信用） | **二维码** | 手机微信 → 右上角「+」→ 扫一扫 |

页面上写着「去哪儿拿」，跟着点就行。**这三样都只存在这台电脑上**，不会上传到任何地方。

---

## 第 3 步：说第一句话

在微信里（或 Telegram 里）给它发一句：

> 你好，看看这个文件夹里有什么

**第一句话就是"认主"** —— 从这句起，只有你这个号能指挥它，别人的消息它一声不吭。
（这是有意的：它是一台能被遥控的电脑。）

它回了你 —— 就成了。🎉

## 装完你就有了

| 想要 | 怎么做 |
| --- | --- |
| 关掉终端窗口也不怕、重开机自己起来 | **在微信里跟它说「帮我设置成开机自动启动」**（它会先问你一声）。管家自己知道 `butler` 在哪（装的时候只改它**自己**的 PATH，不动你的 dotfiles），所以这条路不用你再配什么 —— 成没成，微信「自检」里看得见。⚠️ 万一它说找不到 `butler`（比如安装目录被搬走了），就退一步在终端里跑一次：`~/.butler/prefix/bin/butler autostart on` |
| 看看它现在是好是坏 | `~/.butler/prefix/bin/butler doctor` |
| 从老版本升上来（少了「记忆」「审批」这些） | 再跑一次 `butler init` —— 缺的行它会自己补上，**你改过的东西一个字都不动**（`butler run` 也会提醒你） |
| 换一把模型 key / 换一个机器人 | `~/.butler/prefix/bin/butler run --again` |
| **「它怎么不理我？」/我该说什么** | 认下你之后它会**自己先说一句**（报平安 + 三个能直接抄的例子）。随时回「你能干什么」再看一遍；回「命令」看它都会哪几句。**答得不对就先回「自检」** —— 它会把"要用的程序装没装、记不记得住、要动你电脑之前有没有人问你"挨个查一遍，用人话告诉你哪儿不对。**要是连「自检」都一点动静没有**（那说明它根本没在跑），就**再双击一次 `install.command`**：它会重新把管家开起来，并把哪儿不对写在屏幕上 |
| **不想每件事都被问一遍** | 收到「等你一句话」时回「以后这类都行 2」—— 这一类以后就不问你了（**这一类全部**，连删东西也算）。回「授权」看给过哪些，回「取消授权 1」收回 |
| **只想这一阵子别问** | 同上，尾巴上加个时间：「以后这类都行 2，一小时」（也认 30 分钟 / 两小时 / 一天 / 3 天，最多 7 天）—— **到点它自己恢复**，不用你记着来收。时间没写清楚的那句，它**不会**记成永久授权 |
| **出事了，想找人帮忙** | `butler report` —— 生成一份报告（**里面没有你的任何 key**），把那个文件整个发给帮你的人就行 |
| 出问题时它的日志 | `~/.butler/logs/autostart.log` |
| 所有东西在哪 | `~/.butler/`（配置 `config.json`、凭据 `state/`、收件箱 `inbox/`） |

（嫌 `~/.butler/prefix/bin/butler` 太长：跑一次 `sh install.sh --add-path`，之后直接敲 `butler` 就行，
记得关掉终端窗口重开一个。）

## ★ 卡住了看这里

先跑一次体检，它会把每一处状态和"该怎么办"都打出来：

```sh
~/.butler/prefix/bin/butler doctor
```

| 你看到的样子 | 真正的原因 | 怎么办 |
| --- | --- | --- |
| 双击 `install.command` 说「身份不明的开发者」 | macOS 的安全拦截 | 在它上面**右键 → 打开 → 打开**（一次就够）；还不行就 `sh install.sh` |
| 终端说 `command not found: butler` | `~/.butler/prefix/bin` 不在 PATH 里 | 跑 `sh install.sh --add-path`，然后**关掉终端窗口重开** |
| 终端说「配置读不了」/「文件不存在」 | 还没跑过 `butler init` | 先跑 `butler init`（用 Telegram 就 `butler init --im telegram`） |
| `doctor` 说「Node 版本」✗ | 你系统里那个 `node` 太老 | 重新跑一次 `sh install.sh`（它会自己下一份够新的），重开终端 |
| `doctor` 说「模型 key」✗ | key 没贴、或者跳过了那一步 | 再跑一次 `butler run`，页面会重新问你 |
| `doctor` 说「审批那根线」✗ / 「审批这一侧」✗ | 新版本多出来的那一行还没补上（管家因此**什么敏感操作都不肯干** —— 它宁可不动） | 再跑一次 `butler init`，缺的行它会自己补上 |
| `doctor` 说「审批落盘」✗ | 那个目录写不进去 → 审批一律按「不许」处理 | 照它给的那句话办（腾出目录，或者改配置里那一行的 `dir`） |
| key 贴错了 / 过期了，想换一把 | —— | 跑 `butler run --again`，页面会再问你一次；**不填就还用原来那把**，不会把你的管家弄哑 |
| 贴进去的那把 key 到底行不行 | —— | 页面**当场**替你问一句：对方说不对（401）或者没钱（402），它**压根不让你存**，并告诉你去哪重新复制；只是网络不通就先存下，但会明说「没确认」（要是你确定这把 key 是对的 —— 比如换了别的模型服务商 —— 页面上还有一步「我知道，就要存这一把」） |
| 看到「还没有 Telegram bot token」 | 那串还没贴（或者当时点了跳过） | 跑 `butler run`，页面会问你要；@BotFather 发 `/token` 可以再要一串 |
| 看到「Telegram 说这个 token 不认」 | 复制的时候少了几位，或者它已经作废了 | 找 @BotFather 发 `/token` 重新拿一串，再 `butler run --again` 贴一次 |
| 扫码页一直没弹出来 | 浏览器没被打开（或者这台机器上不了网） | 终端里印着一行 `http://127.0.0.1:…` 的地址，手动粘进浏览器打开 |
| 看到「…超时 —— 重新跑一次 butler run 会重新出码」 | 12 分钟没扫（或者网络断了） | 重新跑 `butler run`，码会重出 |
| 看到「起不来：…」+「是"上线"这一步没过」 | **上面那句话就是原因** | 照着那句话办；拿不准就跑 `butler doctor` |
| 管家**完全不回**你 | ① 你不是"主人"（换了个号发） ② 模型 key 没填 ③ Telegram 的 token 被作废了（`doctor` 会当场说） | `butler doctor`，看「模型 key」「谁能指挥它」「Telegram 登录态」三行 |
| 管家回「（我这边出错了：…）」 | agent 那边真的出错了（最常见的是 key 没额度了） | 括号里那句就是原因；再去 platform.deepseek.com 看看余额 |
| `autostart` 说开着，但重开机没起来 | 系统把它拦了 | 看 `~/.butler/logs/autostart.log` 的最后几十行，再跑 `butler autostart status` |

## 验收清单（走这一遍的人照着打勾）

- [ ] 拿到 tar.gz → 解开 → **双击 `install.command`** 能装完（没有管理员密码）
- [ ] 浏览器**自己弹出了**引导页（不是我手动找的）
- [ ] 引导页上的字**看得懂**（不用去搜"什么是 bot token"）
- [ ] 贴完 key（用 Telegram 的话先贴 token）点保存，页面说「✅ 存好了」
- [ ] 微信这条路：二维码出来了，手机扫得上，终端说「上线了」
- [ ] 在微信里说第一句话，**它回我了**
- [ ] 让它把一张图发给你（例：`把 ~/Desktop/截图.png 发给我`）—— **收到的是图片，不是一个附件**
      （视频同理：`.mp4` / `.mov` 应该在微信里直接能播；`.zip` 这类当然还是文件）
- [ ] 换一个别人的号发消息，**它不理**（这是对的）
- [ ] `butler autostart on` 之后，**关掉终端窗口**，重开机，再发一句 —— 它还回我
- [ ] `butler doctor` 全部是 ✓（或者它明确说清楚哪一条 ✗、怎么办）

### 任何一步卡住，把这四样带回来

1. **卡在第几步**（第 1/2/3 步，或者上面哪一条）
2. **终端里最后那句话的原文**（截图或复制都行）
3. **`butler doctor` 的整段输出**（复制粘贴）
4. 自启动相关的话，再加 **`~/.butler/logs/autostart.log` 的最后 30 行**

> 有这四样，问题基本当场能定位 —— 缺了第 2 条（原文），就只能在猜。

**偷懒版：一条命令把这些收成一个文件**（复制粘贴到终端里回车）：

```sh
{
  echo "== 系统"; uname -a
  echo "== Node"; node -v 2>&1 || echo "（这台机器没装 node）"
  echo "== 管家版本"; ~/.butler/prefix/bin/butler --version
  echo "== 自检"; ~/.butler/prefix/bin/butler doctor
  echo "== 自启动日志（末 30 行）"; tail -30 ~/.butler/logs/autostart.log 2>&1
} > ~/butler-报告.txt 2>&1
```

跑完家里目录下会多一个 `butler-报告.txt`，把它（外加"卡在第几步、终端里最后那句话"）
一起发回来就行。
